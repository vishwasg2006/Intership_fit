# Two-minute demo

All seeded accounts use password `Demo@123`.

1. Log in as `medium@demo.test`. Open **Results** to see the self-reported score and skill breakdown.
2. Open **Gap report**. Point out the score-to-target bars, hours estimate, supplied free resources, and the three-week plan.
3. Open **Matches**. Show how fit is explained, missing requirements are listed, and eligibility is separate from the match score. Use the source link to return to the original listing.
4. Start a **Practice** assessment, accept the rules, and answer a few questions. Use the numbered question navigation to skip around, then submit and review the new score.
5. Log in as `weak@demo.test`. Open **Results** and show the saved terminated attempt. The placement view marks this attempt **Review**.
6. Log in as `placement@demo.test`. On **Dashboard**, point out verified and self-reported scores and review flags. Select a student to open the detail drawer, inspect the attempts, and toggle the shortlist.
7. Back as a student, on **Home** mark interest in an eligible campus drive; the placement **Campus drives** page then shows the response count.
8. Open **Test sessions**, create a supervised session, and show its six-character code. The seed output also prints a separate active demo session code.

Demo accounts: `strong@demo.test` (supervised/Verified), `medium@demo.test` (practice), `weak@demo.test` (terminated/Review), and `placement@demo.test` (placement officer).
